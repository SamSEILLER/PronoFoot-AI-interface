Disponibilités des joueurs

Un parcours simple pour transmettre les matchs à vérifier à ChatGPT, récupérer son fichier complété, puis le contrôler avant de l’ajouter au dépôt.

1

Charger le fichier des matchs à vérifier

Clique sur le bouton : la liste des matchs se charge automatiquement.

Aucun fichier chargé.
En attente du fichier pending.json.
2

Copier le JSON avec le prompt intégré

Le presse-papiers contiendra le prompt de recherche et le fichier pending. Tu peux coller ce JSON dans ChatGPT. Le prompt demande de rendre uniquement le fichier complété, sans enveloppe supplémentaire.

Charge d’abord pending.json.

Le JSON copié est un paquet de travail pour ChatGPT. Ce n’est pas le fichier à déposer dans le dépôt. Le fichier final doit rester un completed.json au format attendu par le moteur.

3

Importer et contrôler completed.json

Après la réponse de ChatGPT, charge son fichier JSON ici. Le contrôle vérifie la structure, les statuts, les sources et les identifiants des matchs avant de préparer son dépôt.

Aucun fichier chargé.
En attente du fichier completed.json.
Ouvrir l’éditeur GitHub

Après le clic, le JSON validé est copié et l’éditeur GitHub s’ouvre. Colle le contenu dans le fichier, puis clique sur Commit changes. Le workflow du moteur lancera automatiquement l’import et l’historisation. Tu dois être connecté à GitHub et avoir accès au dépôt privé.

Les fichiers sont lus et contrôlés dans ton navigateur. Le dépôt final est effectué dans GitHub après ton collage et ta validation du commit.
